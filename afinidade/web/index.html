Como funciona

Comparamos apenas artistas avaliados pelos dois perfis. Quanto menor a distância, mais próximos são os gostos.

d(A,B) = √Σ(Aᵢ − Bᵢ)²
Entenda a recomendação

Os vizinhos são ordenados pela distância euclidiana. Empates favorecem mais avaliações em comum e depois o menor código de usuário.

Para artistas que você ainda não avaliou, calculamos a média das notas dos vizinhos com peso 1/(1 + distância). Apenas médias a partir de 3 viram sugestões. Notas zero não entram no cálculo.
